# Corazon Games

Games is branded Corazon Games, part of the Corazon platform by Crimson Heart,
matching [Corazon Chat](../Chat/README.md): heart-red `#390606` canvas, `#230404`
surfaces, `#FFF1F0` text, one soft rose accent (`#F4A6A1`), Courgette for the
wordmark and a heart favicon.

Canonical source: [`games.html`](games.html).

Production Storage bucket: `liminal-apps`. Keep the production object name `games.html` unchanged.
The `liminal:games:*` postMessage types, `liminalGames.*` storage keys, the
`liminal-games-launcher` presence channel and the `liminal-ugs` game source also
stay unchanged so existing launchers, favorites and usage counts keep working.

Deployment Actions are ready; add repository secrets and verify a dry run. See [deployment setup](../docs/deployment.md).
